STUDENT MANAGEMENT SYSTEM - HOW TO RUN

Step 1: Open VS Code.

Step 2: Open the project folder:
C:\Projects\StudentManagementSystem

Step 3: Make sure the MySQL80 service is running.

Step 4: Open Terminal in VS Code.

Step 5: Run this command:
cd C:\Projects\StudentManagementSystem

Step 6: Run the project:
dotnet run --no-launch-profile -p:UseAppHost=false

Step 7: Open Chrome and enter:
http://localhost:5000

Step 8: To stop the project, press Ctrl + C in the terminal.

Important:
Keep the terminal open while using the website.
